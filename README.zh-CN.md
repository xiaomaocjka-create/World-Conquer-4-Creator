# World Conquer 4 Creator

[English](README.md) | **简体中文**

《世界征服者 4》的本地关卡与地图编辑器。本仓库仅提供 Windows 发布包和版本说明。

## 下载与启动

1. 从 [Releases](https://github.com/xiaomaocjka-create/World-Conquer-4-Creator/releases/latest) 下载 Windows x64 完整包。
2. 将整个发布包解压到可写文件夹。
3. 运行 `WC4EditorLauncher.exe`，按提示完成准备。

发布包自带运行环境，无需安装 Python。需要本机已有兼容的游戏安装；首次使用时，编辑器从本机安装生成所需资源，下载包不附带游戏素材。

当前版本已在维护者的 Windows 11 电脑上验收。编辑器界面保持简体中文；上方语言入口仅切换本说明文档。

## 作品与游戏安装

编辑器在 `%LOCALAPPDATA%\WC4Editor` 下分别保存程序版本、生成资源、作品和备份。更新会保留作品；重要作品仍建议自行备份。

受保护的游戏目录可以作为资源来源。部署需要可写目标，编辑器会拒绝向受保护目录写入，不会移动已安装游戏或修改游戏 EXE。受支持的关卡部署会同时更新对应的关卡校验记录。

## 更新与有效期

更新清单经过签名，下载包经过校验后安装。新版本在下次启动时生效；激活失败会恢复上一版本。

每个版本离线有效期为 14 天，第 11 天开始提示更新。到期后保留查看与导出，编辑及部署需要有效版本。经过签名的线上策略也可以将某个版本设为只读。
